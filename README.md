# Our Love Story — GitHub Pages birthday website

A mobile-friendly, dreamy moon-and-stars birthday website personalized for Satya Swaroopa (nickname: My Mimii Piee).

## Included files
- `index.html` — the complete website
- `images/memory-1.jpg`, `images/memory-2.jpg`, `images/memory-3.jpg` — sample illustrated images; replace these with your own photos when ready
- `audio/romantic-song.wav` — a short, original synthesized instrumental sample; replace it with music you have permission to use if you prefer

## Replace the sample images
Upload your own photos using these exact filenames into the `images` folder:
- `memory-1.jpg`
- `memory-2.jpg`
- `memory-3.jpg`

The included pictures are romantic illustrations, not real photographs. They are only examples to help you preview the layout.

## Music
The included `romantic-song.wav` is an original generated instrumental sample. Browsers usually block autoplay until the visitor taps the screen, so use the Play music button. You can replace it with another supported audio file, but update the audio filename in `index.html` to match.

## Publish with GitHub Pages
1. Extract the ZIP on your computer.
2. Open your `our-love-story` repository on https://github.com.
3. Click **Add file → Upload files**.
4. Upload `index.html`, and upload the contents of `images` and `audio`, keeping the folder names and file names exactly as shown. Existing `.gitkeep` files can remain.
5. Click **Commit changes**.
6. Open **Settings → Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Select branch `main` and folder `/(root)`, then click **Save**.
9. After deployment, the site will be at `https://YOUR-GITHUB-USERNAME.github.io/our-love-story/`.

## Personalize the timeline
Edit `index.html` to replace sample headings and messages with your actual memories. Search for `Chapter 01`, `Chapter 02`, and `Chapter 03`.

## Privacy
GitHub Pages is public. Anyone with the URL can view the site, and files in a public repository can be copied. Only upload photos you are comfortable making public.
